# OTG Events – Milestone 1

## Technology choice
This project uses a lightweight static HTML/CSS setup served locally with Python's built-in HTTP server.

Why this approach:
- no framework overhead or install steps
- reliable VS Code preview and browser compatibility
- fast iteration for design work
- straightforward deployment to GitHub Pages or any static host later

## Local preview
From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
